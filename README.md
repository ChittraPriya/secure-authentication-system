# Secure Authentication System

A modern and secure authentication application designed to provide users with a simple and reliable login experience using email or phone number verification, OTP-based authentication, and biometric security.

## Features

- **User Registration:** Sign up using email address or phone number.
- **User Profile:** Collect date of birth (DOB) and surname during registration.
- **OTP Authentication:** Secure login using a 6-digit verification code.
- **Email Verification:** Send OTP codes and authentication notifications through email.
- **Biometric Authentication:** Support Face ID, fingerprint, and other device-supported biometric authentication.
- **Single Active Device:** Restrict each user account to one active device at a time.
- **Session Management:** Securely manage user sessions and device authentication.
- **Responsive UI:** User-friendly interface for different screen sizes.

## Authentication Flow

1. User registers using email or phone number.
2. User provides date of birth and surname.
3. System verifies the user's email or phone number.
4. User logs in using a 6-digit OTP.
5. User can enable biometric authentication.
6. System ensures only one active device per account.

## Project Objective

To build a secure, user-friendly authentication system that combines OTP verification, biometric login, and device-level session management.

## Future Enhancements

- Login activity and device history.
- OTP expiration and resend functionality.
- Suspicious login detection.
- Secure logout from other devices.
- Rate limiting and brute-force protection.
